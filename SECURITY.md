# Security policy

This repository holds KubeStacks' documentation. To report a vulnerability in KubeStacks
itself, or in these docs, please follow
[KubeStacks' security policy](https://github.com/KubeStacks/KubeStacks/security/policy):
report it privately through a
[GitHub security advisory](https://github.com/KubeStacks/KubeStacks/security/advisories/new),
and please don't open a public issue.

If you find a page that tells people to do something unsafe, that's worth reporting the same
way. Mistakes that aren't a risk can go in an
[issue](https://github.com/KubeStacks/KubeStacks-docs/issues/new/choose) here.
